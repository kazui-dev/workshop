# 配線と設定値

GPIO の割り当ては `src/config.py` を正とする。配線後はこの表と `src/config.py` の BCM GPIO 番号を一致させる。

## 使用部品

- Raspberry Pi Zero WH
- USB カメラ BSWHD06M
- リレー回路
- DC モーター 2 個
- HC-SR04 超音波距離センサー 2 個（前方左・前方右）
- 圧電ブザー
- Raspberry Pi 用電源とモーター用電源

## GPIO 割り当て

| 用途 | BCM GPIO 番号 | コード上の設定 |
| --- | --- | --- |
| 左モーター PWM | `24` | `LEFT_PWM_PIN` |
| 左モーター方向 | `25` | `LEFT_DIR_PIN` |
| 右モーター PWM | `18` | `RIGHT_PWM_PIN` |
| 右モーター方向 | `23` | `RIGHT_DIR_PIN` |
| 前方左 HC-SR04 Trig | `12` | `LEFT_DISTANCE_TRIG_PIN` |
| 前方左 HC-SR04 Echo | `16` | `LEFT_DISTANCE_ECHO_PIN` |
| 前方右 HC-SR04 Trig | `20` | `RIGHT_DISTANCE_TRIG_PIN` |
| 前方右 HC-SR04 Echo | `21` | `RIGHT_DISTANCE_ECHO_PIN` |
| 圧電ブザー | `17` | `BUZZER_PIN` |

Raspberry Pi ヘッダー上の物理 PIN 番号と混同しないこと。実機の配線が異なる場合は `src/config.py` の BCM GPIO 番号を変更する。

HC-SR04 の Echo は 5 V 信号のため、Raspberry Pi の GPIO へ直接接続しない。左右それぞれの Echo に分圧回路または適切なレベル変換を使用し、3.3 V に下げる。

## モーターと通信の設定値

現在の値は `src/config.py` を正とする。

| 設定 | 現在値 | 説明 |
| --- | --- | --- |
| PWM 範囲 | `-255` ～ `255` | 負数は後退、正数は前進、`0` は停止 |
| PWM 周波数 | `1000 Hz` | pigpio に設定する周波数 |
| 操作タイムアウト | `150 ms` | 操作中に受信が途絶えたら停止 |
| WebSocket ポート | `8765` | スマートフォンからの操作通信 |
| HTTP ポート | `8080` | Web UI と MJPEG 映像 |

左右の回転方向が実機と逆の場合は、配線を確認したうえで `LEFT_REVERSE` または `RIGHT_REVERSE` を調整する。最初の動作確認では車体を浮かせ、低い出力から試す。

## 距離計測と障害物判定

| 設定 | 現在値 | 説明 |
| --- | --- | --- |
| トリガー間隔 | `60 ms` | 左右を交互に発振する間隔。各センサーは約 120 ms 周期 |
| Echo タイムアウト | `30 ms` | Echo が完了しない計測を異常値にする時間 |
| 正常距離範囲 | `2` ～ `400 cm` | 範囲外は異常値として操作判定に使わない |
| 障害物判定距離 | `20 cm` | この距離以下でモーターを停止し、前進を抑止する |
| 障害物解除距離 | `25 cm` | 検知後はこの距離以上に離れるまで通常操作へ戻さない |
| 距離異常の連続許容回数 | `3` | 左右それぞれでタイムアウト・範囲外が連続した場合はセンサー異常として停止する |
| ブザー周波数 | `2000 Hz` | 障害物検知中の警告音 |
| ブザーデューティ比 | `128 / 255` | pigpio PWM の出力比 |

起動後は左右両方から解除しきい値以上の距離を取得するまで前進の並進成分を除去し、後退とその場旋回のみ許可する。左右どちらかが障害物を検知している間も同じ操作制限を適用する。両方が解除しきい値以上になると通常操作へ戻り、ブザーを停止する。距離計測のタイムアウトや範囲外の値はセンサーごとに数え、どちらか一方で連続した場合も障害物検知中と同じ停止状態にする。左右のセンサーは超音波の相互干渉を避けるため、同時に発振させず 60 ms 間隔で交互に計測する。
